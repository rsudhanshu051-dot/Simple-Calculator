# This is a simple and interactive calculator created using HTML, CSS, and JavaScript. It allows users to perform basic mathematical operations such as addition, subtraction, multiplication, division, and percentage calculations. These are common features in basic web based calculator projects.

# The calculator has a display screen that shows the entered numbers and the calculated result. It also includes buttons for numbers, operators, decimal values, clearing the display, deleting the last character, and calculating the final answer.

# Main Features
* Addition, subtraction, multiplication, and division.
* Percentage calculation.
* Decimal-number support.
* Clear button to reset the calculator.
* Backspace button to remove the last entered value.
* Equal button to display the result.
* Keyboard support using number keys, operators, Enter, Backspace, and Escape.
* Error handling for invalid calculations.
* Personalized name displayed above the calculator.
